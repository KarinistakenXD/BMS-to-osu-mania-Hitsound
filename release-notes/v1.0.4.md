## Changes

- Select song folders and choose BMS / osu!mania difficulties beside Analyze. Non-mania osu files are rejected.
- Simpler labels with key count, scratch, level or OD/HP. BMS lists sort by keys, scratch count, then level; the hardest estimated chart is selected by default.
- Preview a single chart with original lanes and holds, Master volume, metronome, held-key lights and KPS.
- Added energy-envelope synchronization for ambient audio and Manual Sync Correction after automatic alignment. Note placement updates while editing timing controls; preview audio rebuilds after a short pause.
- Reduced long-lived sample PCM retention with compact features, windowed rendering and a temporary decode cache. Added preview headroom protection; kept the FFmpeg export limiter.
- Added subdivisions and optional visual BPM/SV changes. Improved waveform drag and middle-drag seeking; normal wheel scrolls the page, Alt+wheel seeks.
- Simplified Play/Pause and clear buttons, standardized activity labels, and separated audio-duration progress from elapsed preparation time.
- Preserved compatible-difficulty analysis/audio reuse and preview speed 1–40. Verified external FFmpeg discovery without adding unnecessary ASAR unpacking.

## Notes

- Manual correction shifts the existing fit; Analyze measures alignment again. Base tolerance controls resnap searches rather than audio alignment.
- Osu hardest-chart selection is a note-density estimate, not a star rating. BMS uses declared level.
- Reverse BMS scrolling and SPEED/SP spacing extensions remain unsupported. Full-song audio caches still consume memory; very large charts and unusual ambient pairs should be checked by listening.
